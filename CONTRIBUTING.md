# Contributing to Lunora

Thank you for considering a contribution.

## Before you start

- Search existing issues before opening a new one.
- For substantial changes, open an issue first to discuss the proposed approach.
- Keep pull requests focused and describe the user-visible effect.

## Development

1. Install the Flutter SDK and Windows desktop prerequisites described in `README.md`.
2. Run `flutter pub get`.
3. Run `flutter analyze` and, where applicable, `flutter test`.
4. Test Windows-specific changes on Windows 10/11.

## Pull requests

Include a clear summary, steps to reproduce/fix for bugs, screenshots for UI changes, and notes about any data migrations. Never include personal databases, credentials, API keys, tokens, private certificates, or user exports.
